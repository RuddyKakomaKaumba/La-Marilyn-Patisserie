# La Marilyn — Site vitrine

Home page de la pâtisserie La Marilyn (Next.js · TypeScript · Tailwind CSS).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

## Structure

- `app/` — layout (polices, metadata SEO/Open Graph), page d'accueil, favicon
- `components/` — Header, Hero, GourmetUniverses, Craftsmanship, Occasions, ContactCTA, WhatsAppFloat
- `lib/site.ts` — lien WhatsApp (numéro + message prérempli)
- `public/images/` — photographies et logo
