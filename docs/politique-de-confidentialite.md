## Quelles informations sont collectées ?

Uniquement celles que vous choisissez de saisir dans les formulaires de
demande (« Préparer ma demande », « Composer mon écrin ») :

- votre prénom (facultatif) ;
- la date souhaitée et, selon la demande : occasion, produits et quantités,
  nombre de personnes, budget indicatif, lieu de l'événement ou quartier de
  livraison, couleurs, petit mot à glisser dans l'écrin, précisions libres.

Le site ne demande ni nom complet, ni adresse e-mail, ni numéro de
téléphone : votre numéro est connu de La Marilyn lorsque vous lui écrivez
sur WhatsApp.

## Comment sont-elles transmises ?

Le site **n'enregistre pas** ces informations : il n'a ni base de données ni
envoi vers un serveur. Il les place dans un message WhatsApp pré-rempli, qui
s'ouvre sur votre appareil. **Rien n'est transmis tant que vous n'envoyez
pas ce message vous-même.**

Une fois envoyé, le message est traité par WhatsApp (Meta), conformément à
sa propre politique de confidentialité. Le contenu du message transite dans
l'adresse du lien WhatsApp (wa.me) ouvert par votre navigateur.

et les conditions, et échanger avec vous pour la prestation.

aucun outil de mesure d'audience ni de publicité (vérifié le 14 octobre

site : votre navigateur ne contacte pas Instagram en affichant la page.
